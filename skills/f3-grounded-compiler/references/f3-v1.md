# F3-v1 Canonical Annotation Reference

## Syntax

Return one allowlisted call per line. Strings and numbers are literals. Nested
calls are limited to:

```text
at("path", "time")
event_field("event_id", "quantity")
scale(reference, factor)
fraction(reference, numerator, denominator)
source("exact source span")
cell("exact row label", "exact column label")
```

Do not use assignments, binary expressions, keyword arguments, JSON, comments,
or explanations inside `f3_program`.

## Top-level forms

```text
collection(path, member_kind, location, evidence)
observe(at(path,time), value, unit, evidence)

same(subject, reference, evidence)
offset(subject, reference, signed_delta, unit, evidence)
older_than(subject, reference, delta, unit, evidence)
younger_than(subject, reference, delta, unit, evidence)
multiple(subject, reference, factor, evidence)
fraction_of(subject, reference, numerator, denominator, evidence)
difference_relation(subject, left, right, evidence)
absolute_difference(subject, left, right, evidence)
quotient_relation(subject, numerator, denominator, evidence)
percent_of(subject, reference, percentage, evidence)
percent_more(subject, reference, percentage, evidence)
percent_less(subject, reference, percentage, evidence)
sum_relation(total, part1, part2, ..., evidence)
product_relation(total, factor1, factor2, ..., evidence)
rate_relation(total, rate, duration, evidence)
mean_relation(mean, value1, value2, ..., evidence)
minimum_relation(minimum, value1, value2, ..., evidence)
maximum_relation(maximum, value1, value2, ..., evidence)
member(collection_path, member_path, evidence)
partition(collection_path, total_reference, evidence)

remove(event_id, actor, at(state_path,"current"), quantity, evidence)
add(event_id, actor, at(state_path,"current"), quantity, evidence)
consume(event_id, actor, at(state_path,"current"), quantity, evidence)
produce(event_id, actor, at(state_path,"current"), quantity, evidence)
transfer(event_id, actor, source_reference, destination_reference, quantity, evidence)

query("value", reference)
query("remaining_count", collection_path, time)
query("sum", collection_path, time)
query("mean", reference1, reference2, ...)
query("difference", from_reference, to_reference)
query("absolute_difference", reference_a, reference_b)
query("percentage_ratio", part_reference, whole_reference)
query("percentage_change", from_reference, to_reference)
```

Relations use the semantic subject first. `multiple(a,b,3,...)` means `a` is
three times `b`. `older_than(a,b,6,...)` means `a = b + 6`. Query order follows
the words: percentage change from old to new uses `(old,new)`.

When the question itself requests an average of explicit source values, use
`query("mean", ...)`. Do not add a `mean_relation` target as a solution step.

Use time labels found in the source when possible: `initial`, `current`, `now`,
`2018`, `2019`. For relative age facts, use `plus_2_year` or `minus_3_year`.

## Evidence

For prose, copy a short exact contiguous span:

```text
source("Mara has 12 apples")
```

For a table fact, use the exact row and column labels:

```text
cell("Research and development", "2020")
```

Both labels must be non-empty cells that occur verbatim in the supplied table.
Do not combine stacked headers such as `Ground` and `Leases` into a fabricated
`Ground Leases` label. Do not cite a paragraph or table cell that does not
assert the form.

## Symbolic event quantities

An event quantity may be a number, a semantic path, `at(...)`,
`event_field(...)`, `scale(...)`, or `fraction(...)`. Keep a source-stated
unknown as a path so a later observation can constrain it:

```text
observe(at("trader.rice.count", "initial"), 55, "count", source("55 bags of rice in stock"))
remove("sale", "trader", at("trader.rice.count", "current"), "trader.rice.sold.count", source("sells off some bags of rice"))
add("restock", "trader", at("trader.rice.count", "current"), 132, source("restocks 132 bags of rice"))
observe(at("trader.rice.count", "now"), 164, "count", source("now has 164 bags of rice"))
query("value", event_field("sale", "quantity"))
```

Do not invent denomination or unit-conversion facts that the source does not
state. F3-v1 records requiring such external ontology knowledge are
`unsupported` rather than silently normalized.

## Fixed synthetic examples

### Event and coreference

Input:

```text
A bin contains 18 red balls and 10 blue balls. Lina removes 3 red balls.
Omar removes 2 red balls and three times that many blue balls. How many balls remain?
```

Output:

```text
collection("bin.balls", "ball", "bin", source("18 red balls and 10 blue balls"))
observe(at("bin.balls.red.count", "initial"), 18, "count", source("18 red balls"))
observe(at("bin.balls.blue.count", "initial"), 10, "count", source("10 blue balls"))
remove("e1", "lina", at("bin.balls.red.count", "current"), 3, source("Lina removes 3 red balls"))
remove("e2", "omar", at("bin.balls.red.count", "current"), 2, source("Omar removes 2 red balls"))
remove("e3", "omar", at("bin.balls.blue.count", "current"), scale(event_field("e2", "quantity"), 3), source("three times that many blue balls"))
query("remaining_count", "bin.balls", "current")
```

### Declarative relation and time

Input:

```text
Nora is four years older than Luis. In three years, Luis will be 19. How old is Nora now?
```

Output:

```text
older_than(at("nora.age", "now"), at("luis.age", "now"), 4, "year", source("Nora is four years older than Luis"))
observe(at("luis.age", "plus_3_year"), 19, "year", source("In three years, Luis will be 19"))
query("value", at("nora.age", "now"))
```

### Static table grounding

Input table:

```text
Metric | 2021 | 2020
Cloud services expense | 30 | 20
Total expense | 90 | 80
```

Question: What was the percentage change in cloud services expense from 2020 to 2021?

Output:

```text
observe(at("company.cloud_services_expense", "2021"), 30, "currency", cell("Cloud services expense", "2021"))
observe(at("company.cloud_services_expense", "2020"), 20, "currency", cell("Cloud services expense", "2020"))
query("percentage_change", at("company.cloud_services_expense", "2020"), at("company.cloud_services_expense", "2021"))
```

## Boundary

If a source assertion cannot be represented by the allowlist, set
`f3_status="unsupported"` and return an empty program. Do not approximate it with
a misleading relation. Do not calculate hidden values and re-label them as
observations.
